# Сейчас — MVP для общения рядом

Это не дейтинг. Пользователь включает статус до ручного выключения, выбирает занятие, видит активных людей и встречи рядом и может отправить отклик.

## Что работает

- безопасный вход из Telegram Mini App с серверной проверкой `initData`;
- PostgreSQL на Railway и SQLite для локальной разработки;
- реальные пользователи, геолокация, постоянный статус с напоминанием через час;
- встречи и повторно-безопасные отклики;
- уведомления в приложении, добровольные Telegram-уведомления и отдельная доставка жалоб администраторам;
- доверие по завершённым встречам, благодарностям и неявкам;
- полноценные точки мест встречи с названием и координатами;
- возвращаемые приглашения и отметка «Развивает клуб»;
- радиус 3/5/10/12 км;
- приблизительные зоны на карте и диапазоны расстояния;
- гостевой просмотр публичных акций без персональных карточек.

## Переменные Railway

- `DATABASE_URL` — добавляется сервисом PostgreSQL;
- `SECRET_KEY` — случайная длинная строка;
- `SELFIE_ENCRYPTION_KEY` — отдельная случайная длинная строка для шифрования селфи;
- `SELFIE_ENCRYPTION_KEY_VERSION` — версия текущего ключа, например `v1`;
- `PUBLIC_URL` — публичный адрес Railway без завершающего `/`;
- `TELEGRAM_BOT_TOKEN` — токен `@vmeste_rjadom_bot` (старое имя `BOT_TOKEN` тоже поддерживается);
- `ADMIN_TELEGRAM_IDS` — Telegram ID администраторов через запятую, без имён пользователей;
- `ENABLE_SSE=false` — SSE не используется как основной production-механизм синхронизации;
- `ALLOW_TEST_AUTH=false`.

В Railway также необходимо задать `APP_ENV=production`. В production приложение
завершает запуск, если отсутствует обязательная конфигурация, используется не
PostgreSQL/HTTPS, включён тестовый вход или схема БД не находится на Alembic
revision `0012_task_alerts`. Временный production-ключ не генерируется.

`TELEGRAM_CLIENT_ID` и `TELEGRAM_CLIENT_SECRET` нужны только для необязательного входа из обычного браузера. Основной вход Mini App использует `TELEGRAM_BOT_TOKEN`.

## Возможности 0.18.1

- Встречу можно назначить на любое оставшееся время текущего дня по Минску.
- Приглашение открывает самостоятельное PWA. Старые ссылки Telegram продолжают
  действовать. Пополнение лимита происходит после первой завершённой встречи приглашённого.
- Уведомления Telegram включаются в профиле. Пользователю нужно открыть бота
  и нажать «Запустить». После первого совпадения подписка «Сообщить, когда
  появится компания» завершается. Поиск учитывает занятие, радиус и срок.
  При неопределённом ответе Telegram доставка автоматически не повторяется.
  Напоминание об открытости не выключает статус.
- `PRIVATE_TASK_TELEGRAM_IDS` задаёт список Telegram ID участников закрытого
  раздела «Поручения» через запятую. Администраторы имеют доступ для модерации.
  Разрешены только перечисленные в интерфейсе дистанционные категории. Сумма
  в BYN справочная. Платёжной интеграции нет.
- В панели модерации раздел «Источники привлечения» создаёт ссылки и показывает
  визиты и регистрации по каналам `press`, `creator` и `ads`. Используйте
  `utm_source` для площадки, `utm_campaign` для кампании и `utm_medium` для
  канала. Регистрация учитывается один раз, если метка передана в течение
  суток после создания аккаунта.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Destructive PostgreSQL concurrency tests разрешены только для отдельной
одноразовой БД, когда `DATABASE_URL` точно совпадает с `TEST_POSTGRES_URL` и
явно задано `ALLOW_DESTRUCTIVE_TEST_DB=true`.

Railway запускает приложение командой из `Procfile`.

## Windows и Docker Desktop

В Docker Desktop включите режим Linux containers (WSL 2). Из корня репозитория запустите в PowerShell:

```powershell
.\scripts\start-windows.ps1
.\scripts\start-windows.ps1 -Demo
.\scripts\start-windows.ps1 -Rollback
```

Первая команда запускает или обновляет приложение на [127.0.0.1:8080](http://127.0.0.1:8080/).
При обновлении скрипт сохраняет снимок SQLite, ключи из `.env` и тег предыдущего образа.
Откат возвращает последний полный снимок со старым образом. Изменения после создания снимка при этом теряются.

`-Demo` открывает [127.0.0.1:8081/demo](http://127.0.0.1:8081/demo) с переключением ролей,
отдельной БД и локальным просмотром имитированных уведомлений Telegram. Роли и данные демо
доступны только при запуске отдельного образа. `-NoBrowser` оставляет браузер закрытым.

База обычного приложения сохраняется в томе `app-data`, демо — в отдельном томе проекта
`sichas-demo`. Храните копии из `local-backups` вместе с ключами в защищённом месте.
