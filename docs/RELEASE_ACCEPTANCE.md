## Внешняя приёмка перед разрешением запуска

1. Владелец выделяет отдельного Telegram-бота и разрешённый публичный HTTPS-хост.
   На двух аккаунтах проверяются вход, сохранение устройства, PWA-приглашение,
   уведомление о компании и напоминание через час при закрытом PWA, затем отзыв
   согласия.
2. На физических Android и iPhone проверяются установка, системные разрешения,
   навигация, доступность и восстановление соединения. На Windows Docker Desktop
   выполняется автоматический запуск из подготовленного скрипта.
3. На целевом хосте проверяются TLS, оповещения по /ready, фоновые задачи и
   восстановление из защищённого архива. Допуск к эксплуатационной нагрузке
   определяется на этом хосте.
4. Владелец и юрист согласуют документы для Беларуси, порядок проверки
   организаторов, координаторов, сроки хранения и порядок обработки инцидентов.
   Владелец подтверждает слияние и публичный запуск. Реальные платежи и выплаты
   остаются отключёнными.
